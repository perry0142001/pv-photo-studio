PV Photo Studio — Starter
=========================

This is a starter web app for a Photoshop-like editor. It supports:
- Opening an image
- Selecting, moving, resizing and rotating objects
- Adding text and rectangles
- Basic layer selection and ordering
- Undo/redo
- Basic image brightness/contrast
- PNG export
- Mobile-friendly layout

IMPORTANT
- The app loads Fabric.js from a CDN, so internet is required when you open it.
- This is a starter, not a full Photoshop replacement.
- Use a modern browser.
- Export your work before closing the page; project files are not yet saved/reopened.
- Gujarati text display depends on fonts available in the browser/device. If glyphs do not display correctly, install/use a Gujarati-capable font and add it to the font menu in a later version.

RUN ON WINDOWS
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html to try it in Chrome or Edge.
4. If browser restrictions interfere, use VS Code and a local static server extension.

RUN ON ANDROID
Easiest for testing: transfer the folder to the phone and open index.html in a browser/file viewer. Some file managers may block local scripts. A more reliable next step is to host it on a static web host or run a local server. Hosting may have free options but requires setup.

Files:
- index.html: app layout
- style.css: visual design and responsive layout
- app.js: editor behavior
