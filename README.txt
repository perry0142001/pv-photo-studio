PV Photo Studio Pro starter project

Upload all four files to the ROOT of your GitHub repository:
index.html, style.css, app.js, README.txt.
Use exact names and replace the previous versions of index.html, style.css and app.js.
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

Includes photo import, Gujarati/English text, quick poster text, shapes, canvas sizes/background, basic layers, brightness/contrast/saturation/grayscale, undo/redo, PNG/JPG export and mobile responsive layout.

This is a starter editor, not a full Adobe Photoshop replacement. Internet is required for Fabric.js and online fonts.
